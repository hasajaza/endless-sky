# Endless Sky Accessible: downloads

Windows downloads of Endless Sky Accessible, an unofficial screen reader accessibility mod for Endless Sky 0.11.4. Not made or endorsed by the Endless Sky developers. Developed with AI assistance (Claude, by Anthropic).

## Latest version: 1.0.24

- [EndlessSky_Access_1.0.24.zip](https://github.com/hasajaza/endless-sky/raw/downloads/EndlessSky_Access_1.0.24.zip): extract it and run Install.bat. Requires Endless Sky 0.11.4, which is free: from [Steam](https://store.steampowered.com/app/404410/Endless_Sky/) or the official GitHub download [EndlessSky-win64-v0.11.4.zip](https://github.com/endless-sky/endless-sky/releases/tag/v0.11.4).

Release notes: [RELEASE_NOTES_1.0.24.md](RELEASE_NOTES_1.0.24.md).

Documentation and source code: the [accessibility branch](https://github.com/hasajaza/endless-sky/tree/accessibility/accessibility).
